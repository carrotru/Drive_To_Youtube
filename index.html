Drive 影片上傳 YouTube

先看自己是哪種情境，再照那個情境的四個 Cell 依序執行。專案：youtube-uploader-503204

先選情境
情境一
同帳號 → 同頻道

影片在自己的 Drive，也是傳到自己的 YouTube 頻道。Cell 1 跟 Cell 3 登入同一個帳號。

情境二
A 帳號 → B 頻道

影片在 A 帳號的 Drive，要傳到 B 帳號的 YouTube 頻道。Cell 1 登入 A，Cell 3 登入 B。

YouTube 授權

登入同一個自己的帳號
python · colab cell 
from google_auth_oauthlib.flow import InstalledAppFlow
from googleapiclient.discovery import build

SCOPES = ["https://www.googleapis.com/auth/youtube.upload"]
CLIENT_ID = "你的CLIENT_ID"
CLIENT_SECRET = "你的CLIENT_SECRET"

flow = InstalledAppFlow.from_client_config(
    {"installed": {
        "client_id": CLIENT_ID,
        "client_secret": CLIENT_SECRET,
        "auth_uri": "https://accounts.google.com/o/oauth2/auth",
        "token_uri": "https://oauth2.googleapis.com/token",
        "redirect_uris": ["http://localhost"]
    }}, SCOPES)
flow.redirect_uri = "http://localhost:8080"

auth_url, _ = flow.authorization_url(prompt="consent")
print(auth_url)
code = input("貼上網址列 code= 到 & 之間的那串：")
flow.fetch_token(code=code)
creds = flow.credentials
youtube = build("youtube", "v3", credentials=creds)
4

上傳

python · colab cell 
from googleapiclient.http import MediaFileUpload

VIDEO_PATH = "/content/drive/MyDrive/資料夾/檔名.mp4"

request = youtube.videos().insert(
    part="snippet,status",
    body={
        "snippet": {"title": "標題", "description": "描述", "categoryId": "22"},
        "status": {"privacyStatus": "unlisted"}
    },
    media_body=MediaFileUpload(VIDEO_PATH, resumable=True, chunksize=1024*1024*10)
)
response = None
while response is None:
    status, response = request.next_chunk()
    if status:
        print(f"{int(status.progress()*100)}%")
print("https://youtu.be/" + response["id"])

myaccount.google.com/permissions 前往 →

第一次用的人怎麼設定

以下只需要做一次，之後每次上傳都可以跳過，直接從情境一或情境二的 Cell 1 開始。

1

建立 Google Cloud 專案

新增一個專案（例如就叫 youtube-uploader），之後所有設定都在這個專案底下做。

console.cloud.google.com 前往 →
2

啟用 YouTube Data API v3

左側選單「API 和服務」→「程式庫」，搜尋 YouTube Data API v3，點進去按「啟用」。

3

設定 OAuth 同意畫面

「API 和服務」→「OAuth 同意畫面」，User Type 選「外部」，應用程式名稱隨便填，Scopes 加上 youtube.upload。存下去即可，因為只有自己在用，不用送審。

4

把會用到的帳號加進 Test users

情境一只要加自己；情境二要把 A 跟 B 兩個帳號都加進去，沒加的帳號在 Cell 3 授權時會被拒絕。

console.cloud.google.com/auth/audience 前往 →
5

建立 OAuth Client ID

「API 和服務」→「憑證」→「建立憑證」→「OAuth 用戶端 ID」，應用程式類型選「電腦應用程式」（Desktop app）。建立後會拿到一組 Client ID 跟 Client Secret。

6

把 CLIENT_ID / CLIENT_SECRET 貼進 Cell 3

把上一步拿到的兩串值，貼到 Cell 3 程式碼裡 CLIENT_ID 跟 CLIENT_SECRET 的位置。存好之後可以一直重複用，不用每次重建。

常見問題自查

  • Cell 3 授權被拒絕 → 該帳號沒被加進 Test users，回第一次設定第 4 步加進去
  • 傳到錯的頻道 → Cell 3 授權時登入的帳號不是預期中的 B，重新跑一次並看清楚畫面上的帳號
  • 找不到影片檔案 → 確認 Drive 掛載的帳號，跟影片實際存放的帳號是同一個
  • 下次要用卻要重新設定 → CLIENT_ID / CLIENT_SECRET / Cloud 專案不用刪，直接沿用
